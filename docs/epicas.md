## E0. Fundamentos del proyecto

**Objetivo:** dejar definidos el alcance, la arquitectura, la base de datos y el entorno antes de desarrollar funcionalidades.
**Tipo:** épica técnica (historias técnicas, no historias de usuario).
**Historias:** ver [historias.md → E0](historias.md#e0)

<a id="e1"></a>

## E1. Autenticación y registro

**Objetivo:** que el cliente tenga una cuenta propia para realizar pedidos y dar seguimiento a sus compras.
**Historias:** ver [historias.md → E1](historias.md#e1)

<a id="e2"></a>

## E2. Catálogo de productos

**Objetivo:** que el cliente encuentre rápidamente los platos disponibles y tenga la información necesaria para elegir.
**Historias:** ver [historias.md → E2](historias.md#e2)

<a id="e3"></a>

## E3. Carrito de compras

**Objetivo:** que el cliente arme su pedido con claridad sobre cantidades y costos.
**Historias:** ver [historias.md → E3](historias.md#e3)

<a id="e4"></a>

## E4. Checkout y pagos

**Objetivo:** que el cliente complete su compra con el método de pago que prefiera (tarjeta o contraentrega).
**Historias:** ver [historias.md → E4](historias.md#e4)

<a id="e5"></a>

## E5. Perfil del cliente

**Objetivo:** que el cliente gestione su información y conozca el estado de sus pedidos.
**Historias:** ver [historias.md → E5](historias.md#e5)

<a id="e6"></a>

## E6. Panel de administración

**Objetivo:** que Salazar SAC opere la tienda: carta, disponibilidad, pedidos y ventas.
**Historias:** ver [historias.md → E6](historias.md#e6)
